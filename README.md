# 롤챔봇 (LolChampBot)

경쟁전 시작 전 포지션과 난이도에 맞는 챔피언과 동일 포지션 밴 후보를 제안하는 Discord 봇입니다.

## 현재 데이터 범위

현재 로컬 데모 데이터에서 추천 가능한 범위는 **미드 · 쉬움 6명**, **미드 · 보통 3명**입니다. 탑·정글·원딜·서포터와 미드 · 어려움은 준비 중입니다. 이 목록은 코드에 고정되어 있지 않고 로드한 통계와 챔피언 데이터를 기준으로 계산됩니다.

준비 중인 포지션이나 난이도를 선택해도 세션은 유지됩니다. 데이터 부족 화면에서 `다른 난이도 선택`, `다른 포지션 선택`, `현재 지원 범위 확인`, `종료`를 사용해 언제든 복구하거나 종료할 수 있습니다. 추천 후보가 1~3명인 조건은 해당 수만큼만 표시하며, 최대 4명입니다.

## 데이터와 통계 제공자

`ChampionStatsProvider`는 JSON 제공자와 향후 외부 제공자를 교체할 수 있도록 분리되어 있습니다. 통계는 승률·픽률·밴률을 내부적으로 0~1로 보관하고, 화면에서는 퍼센트로 표시합니다. 표본 경기 수, 패치, 티어 구간, 지역, 갱신 시각, 출처 및 데모 여부도 함께 보관합니다. 현재 JSON의 기존 필드는 호환 변환되며, 누락된 밴률은 **데모 데이터의 기본값**으로만 처리됩니다.

현재 자동 수집은 구현되어 있지 않고, 화면의 출처는 `로컬 샘플 데이터`로 표시됩니다. 따라서 표본 통계는 실제 경쟁전 데이터와 다를 수 있습니다. 통계 제공자가 빈 결과를 주거나 실패해도 서버 오류로 취급하지 않고 복구 가능한 데이터 부족 화면을 표시합니다.

### LOL.PS 검토 상태

LOL.PS를 향후 통계 출처 후보로 검토하고 있으나, 2026-07-27 기준으로 공개 개발자 API, 데이터 재사용·재배포·상업적 공개 Discord 봇 사용, 요청 제한, 출처 표기에 대한 공식 허가 문서를 확인하지 못했습니다. 따라서 LOL.PS 웹페이지 크롤링, 비공개 엔드포인트 사용, HTML 파싱은 구현하지 않았습니다.

“현재 LOL.PS 자동 연동은 구현되지 않았으며, 데이터 사용 조건과 공식 제공 방법을 확인한 뒤 적용할 예정입니다.” 공식 API 또는 서면 사용 허가가 확인되면 `LolPsChampionStatsProvider` 같은 구현체를 추가하고, 봇 화면과 이 문서에 적절히 출처를 표기할 예정입니다. 롤챔봇은 LOL.PS와 제휴하거나 공식 인증을 받은 프로젝트가 아닙니다.

## 설치와 실행

```bash
npm install
cp .env.example .env
# .env에 Discord 애플리케이션의 토큰과 클라이언트 ID 입력
npm run deploy:commands
npm run dev
```

Discord Developer Portal에서 Bot을 만들고 `applications.commands`, `bot` 스코프로 서버에 초대하세요. `.env`와 토큰은 커밋하지 않습니다.

## 구조와 알고리즘

- `src/bot.ts`: Discord UI, 복구 화면, 상호작용 권한/만료 처리
- `src/services/recommendation.ts`: 추천·밴 점수, 결과 타입, 동적 지원 범위
- `src/data/providers.ts`: JSON 스키마 검증·하위 호환·교체 가능한 통계 제공자

난이도는 여섯 난이도 요소의 가중 평균입니다. 추천 점수는 정규화된 승률 55%, 픽률 25%, 표본 신뢰도 20%입니다. 밴률은 추천 점수에 섞지 않고 플레이 가능성을 판단할 보조 정보로 표시합니다. 밴 추천은 매치업 불리함 60%, 상대 픽률 25%, 표본 신뢰도 15%를 사용합니다.

## 검증과 수동 확인

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build`를 실행합니다.

Discord 개발 서버에서 `/챔피언추천`을 실행한 뒤 서포터 또는 미드 · 어려움을 선택하고, 복구 버튼·종료 버튼·지원 범위 버튼이 동작하는지 확인하세요. 이어서 미드 · 쉬움/보통을 선택해 추천 수와 챔피언 버튼 수가 같은지 확인하면 됩니다.
